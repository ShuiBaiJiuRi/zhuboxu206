Mermaid 语法速查
SYNTAX

    

      
1
初始化
mermaid.initialize({ startOnLoad:false, theme:'dark' }) 配置全局；mermaid.render(id, src) 返回 SVG 字符串，也可让 mermaid.run() 自动替换页面上的 .mermaid 元素。

      
2
节点与连线
A["矩形"]、D{"菱形判断"}、A -- "标签" --> B、A -. "虚线" .-> B；<br/> 在标签内换行。

      
3
子图与样式
subgraph KB["离线管线"] … end 划分子系统；classDef 定义配色，class A,B,C online 批量套用。

      
4
ER 关系基数
||--o{ 一对多、}o--o| 多对零或一、||--|| 一对一；关系后用 : "动词" 标注语义。

      
5
实体属性
实体名后跟 { }，每行「类型 字段名 约束 "注释"」；约束支持 PK / FK / UK。

      
6
重绘与导出
改配置后重新 render() 并注入 SVG；多图重绘要串行执行（Mermaid 渲染过程不可重入）。生成的 SVG 可直接 XMLSerializer 导出。

    


    
// ① 引入本地 UMD 构建（离线可用，提供全局 mermaid 对象）
<script src="./cdn/mermaid/mermaid.min.js"></script>

// ② 初始化配置
mermaid.initialize({
  startOnLoad: false,
  theme: 'dark',
  securityLevel: 'loose',
  flowchart: { htmlLabels: true, curve: 'basis' },
  er: { layoutDirection: 'TB' }
});

// ③ 图 1：流程图（源码写在 .mermaid 元素的文本里）
<div class="mermaid">
graph TD
  U["用户提问"] --> I["意图识别"]
  I --> D{"信息充分?"}
  D -- "否" --> Q["澄清追问"]
  Q --> U
  D -- "是" --> R["混合检索"]
  subgraph KB["离线知识构建"]
    K1["多源语料"] --> K2["解析/分块"] --> K3["混合索引"]
  end
  K3 -. "知识供给" .-> R
  classDef online fill:#12304a,stroke:#67e8f9,color:#e5eefc;
  class U,I,R online;
</div>

// ④ 图 2：ER 图
<div class="mermaid">
erDiagram
  USER ||--o{ SESSION : "发起"
  SESSION ||--o{ MESSAGE : "包含"
  MESSAGE ||--o| ANSWER : "触发"
  USER {
    bigint user_id PK
    bigint tenant_id FK
    string nickname
  }
</div>

// ⑤ 方式 A：自动把 .mermaid 元素替换为 SVG
await mermaid.run({ querySelector: '.mermaid' });

// ⑤ 方式 B（本页采用）：显式渲染，便于多图重绘与导出
const { svg } = await mermaid.render('diagram-1', sourceText);
host.innerHTML = svg;
