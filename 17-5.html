JavaScript 的两种定时器

setTimeout：延迟一段时间后只执行一次；setInterval：每隔固定时间反复执行。 下面两个演示都真实调用浏览器的定时器，你可以改时间、随时启动或取消，直观看到它们的区别。

setTimeout 只执行一次

设定一个延迟时间，时间到后执行一次回调，然后自动结束。想“过一会儿再做某事”就用它。

毫秒
0
已执行次数
尚未启动
点击「启动」按钮开始计时。
const id = setTimeout(() => {
  alert('时间到！');
}, 2000);

// 取消定时器
clearTimeout(id);

setInterval 反复执行

每隔固定时间就执行一次回调，不会自己停，必须调用 clearInterval 才能停止。适合时钟、轮播、轮询。

毫秒
0
已执行次数
运行时长 0.0 s
点击「开始」按钮，它会一直重复执行。
let n = 0;
const id = setInterval(() => {
  console.log('第', ++n, '次');
}, 500);

// 不停止就会一直执行下去
clearInterval(id);
