JavaScript 6 种基本数据类型

朱泊旭的 JavaScript 项目 — 基本数据类型演示

1. 字符串 String typeof → "string"
由零个或多个字符组成的有序序列，可以使用单引号、双引号或反引号（模板字符串）来表示。
代码示例
var str1 = "你好"; var str2 = 'JavaScript'; var str3 = `欢迎 ${str2}`;
运行结果
2. 数字 Number typeof → "number"
包括整数和浮点数，还有特殊值 NaN（Not a Number）和 Infinity（无穷大）。所有数字都是 64 位浮点数。
代码示例
var num1 = 42; var num2 = 3.14; var num3 = -100; var num4 = 1e6;
运行结果
3. 布尔值 Boolean typeof → "boolean"
只有两个取值：true 和 false，常用于条件判断。注意：0、""、null、undefined、NaN 在条件中都会转换为 false。
代码示例
var isOnline = true; var isError = false; var hasValue = Boolean("hello"); var noValue = Boolean(0);
运行结果
4. 空值 Null typeof → "object"（历史遗留bug）
表示一个空对象指针，专门用来表示"无值"。注意：typeof null 返回 "object" 是 JavaScript 的一个历史遗留 bug。
代码示例
var empty = null; console.log(empty); console.log(empty === null);
运行结果
5. 未定义 Undefined typeof → "undefined"
表示变量已声明但尚未赋值，或者访问不存在的对象属性。undefined 也是全局对象的一个属性。
代码示例
var x; var obj = {}; console.log(x); console.log(obj.foo); console.log(undefined === x);
运行结果
6. 符号 Symbol typeof → "symbol"
ES6 新增的基本类型，表示唯一的、不可变的标识符。常用于对象属性键，确保属性名不会冲突。
代码示例
var sym1 = Symbol(); var sym2 = Symbol("描述"); var sym3 = Symbol("描述"); console.log(sym2 === sym3); // false
运行结果
