ECharts 关键配置项

API NOTES
1

初始化与渲染

echarts.init(dom) 拿到实例，setOption(option, true) 全量替换配置；第二个参数 true 表示不与旧配置合并，切主题时必须带上。

2

series 与双轴

柱与折线放在同一个 series 数组；折线用 yAxisIndex: 1 绑定右侧百分比轴，两根轴分别写进 yAxis: []。

3

tooltip.formatter

传入回调函数，用 params 数组自定义悬浮内容，可插入 HTML；本页把当月总量、两项构成和解决率拼成一张小表。

4

dataZoom / toolbox

dataZoom: [{type:'inside'}, {type:'slider'}] 支持滚轮与滑块；toolbox.feature 提供数据视图、magicType、还原与导出图片。

5

事件与联动

chart.on('click', ...) 监听扇区点击，改数据源后重新 setOption，即可实现两图联动；也可用 dispatchAction 主动高亮。

6

响应式

容器尺寸变化后必须调用 chart.resize()；本页同时监听 window.resize 与 ResizeObserver。

// ① 引入本地 ECharts（相对路径，离线可用）
<script src="./cdn/echarts/echarts.min.js"></script>

// ② 初始化两个实例
const c1 = echarts.init(document.getElementById('chart1'));
const c2 = echarts.init(document.getElementById('chart2'));

// ③ 图 1：堆叠柱 + 双轴折线
c1.setOption({
  tooltip: { trigger: 'axis' },
  xAxis:  { type: 'category', data: months },
  yAxis:  [{ type: 'value', name: '咨询量' },
           { type: 'value', name: '解决率', max: 100 }],
  dataZoom: [{ type: 'inside' }, { type: 'slider' }],
  toolbox: { feature: { dataView: {}, magicType: {}, restore: {}, saveAsImage: {} } },
  series: [
    { name: '自助解决量', type: 'bar', stack: 'total', data: solved },
    { name: '转人工量',   type: 'bar', stack: 'total', data: human },
    { name: '自助解决率', type: 'line', yAxisIndex: 1, smooth: true, data: rates }
  ]
}, true);

// ④ 图 2 → 图 1 联动
c2.on('click', p => {
  if (p.seriesType !== 'pie') return;
  renderChart1(dataOf(p.name));   // 重新 setOption(option, true)
});

// ⑤ 容器尺寸变化后重绘
window.addEventListener('resize', () => { c1.resize(); c2.resize(); });
