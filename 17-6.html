异步演示：包饺子

用 Promise + async / await 把一个真实的流程写成异步代码：先买原料（6s），再去取原料（2s）， 然后同时和面（4s）与和馅（5s）——用 Promise.all 让两件事并行；两者都完成后包饺子（3s），最后吃饺子（2s）。 每一步都用 setTimeout 模拟耗时，页面上实时显示流程进度。

🎉 热腾腾的饺子出锅啦，开吃！

核心代码

1async function makeDumplings() {
2 await buyIngredients(); // 买原料 6s
3 await pickupIngredients(); // 取原料 2s
4 await Promise.all([ // 同时开始 ↓
5 kneadDough(), // 和面 4s
6 makeFilling() // 和馅 5s
7 ]);
8 await wrapDumplings(); // 包饺子 3s
9 await eatDumplings(); // 吃饺子 2s
10 log('全部完成 🥟');
11}
12
13// 用 setTimeout 把"耗时"包装成 Promise
14const wait = ms => new Promise(r => setTimeout(r, ms));

高亮的行表示当前正在执行的那一步。注意第 4—7 行：Promise.all 里的两个任务会同时开始，全部完成后才继续往下走。
