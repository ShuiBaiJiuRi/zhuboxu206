它是怎么做出来的

核心思路
1

离屏采样

先在内存画布上写白色文字，用 getImageData() 读取 alpha 通道，按固定步长取点，得到「文字的像素坐标表」。

2

弹簧物理

每个粒子有位置、速度、目标点。每帧 v += (target - pos) × k，再乘阻尼，就能自然地飞回并轻微回弹。

3

叠加发光

绘制粒子时切到 globalCompositeOperation = 'lighter'，颜色叠加出霓虹感，再加一条横向扫光。

4

设备像素比

canvas.width = 逻辑宽 × dpr 后 setTransform 缩放，高分屏上文字才不会发虚。

// ① 把文字变成坐标点
const off = document.createElement('canvas');
off.width = W; off.height = H;
const o = off.getContext('2d');
o.font = '900 200px "Microsoft YaHei"';
o.textAlign = 'center'; o.textBaseline = 'middle';
o.fillText('朱泊旭', W / 2, H / 2);
const data = o.getImageData(0, 0, W, H).data;
for (let y = 0; y < H; y += 5)
  for (let x = 0; x < W; x += 5)
    if (data[(y * W + x) * 4 + 3] > 100) points.push({ x, y });

// ② 每帧把粒子拉回目标点（不同模式只改 target）

p.vx *= 0.86;  p.vy *= 0.86;
p.x += p.vx;  p.y += p.vy;

// ③ 一个帧循环驱动全部画布
