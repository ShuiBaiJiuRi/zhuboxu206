    关键设计要点

    高并发电商

    缓存与读多写少

    商品详情、类目、首页数据放 Redis，用「先删缓存再更新库 + 过期时间」降低不一致风险。

    MQ 削峰解耦

    下单后把发货、短信、积分、数据同步交给 RocketMQ，核心链路只保留必要同步调用。

    库存防超卖

    Redis 预扣减 + 数据库最终一致，配合幂等键与分布式锁，避免重复下单和超卖。

    搜索与库分离

    商品变更通过消息同步到 Elasticsearch，复杂检索不压 MySQL，主库只承担事务写入。

    网关统一治理

    鉴权、限流、灰度、熔断集中在 API 网关；Nacos 负责服务注册与配置下发。

    可观测与安全

    全链路日志进 ELK，指标进 Prometheus / Grafana，风控服务识别刷单与异常支付。
